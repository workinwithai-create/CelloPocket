# CelloPocket

Live cello desk for bedroom producers and AI-music finishers.

Paint warm cello sustained lines and arpeggios over your own BPM, key and 4-chord progression. Real FluidR3 cello samples. Grid-perfect WAV + MIDI export so the loop drops into your DAW on the downbeat.

Helps finish sparse tracks with emotional string depth. Distinct from FluteForge (airy tops), ChopFour (nylon chops), PianoPocket, BassForge, etc.

## Features
- Your track first: BPM 60-180, key, mode, chords (e.g. Am F C G), bars.
- Recipes: Sustained roots, Arpeggio walk. Changes apply live on next step.
- Live instrument sounds only (pinned FluidR3 cello).
- Lookahead scheduler on AudioContext clock.
- Export: 48 kHz 24-bit stereo WAV (exact length, sample 0 = downbeat, seamless loop), matching MIDI.
- Web MIDI keyboard support.
- Settings persist in localStorage.
